# AI辅助宠物营养配比推荐与鲜食库存管理系统 (多模块导航 + 登录注册升级版)

## 一、 系统升级特性
1. **统一登录与注册认证模块 (JWT)**：
   * 支持用户注册、账号密码登录及身份权限切换；
   * 内置系统管理员 (`admin / 123456`) 与宠主用户 (`petlover / 123456`) 快捷账户。
2. **多页面/模块侧边栏导航切换**：
   * 🤖 **AI 营养配比与食谱推荐**：基于 NRC 标准动态测算每日能量需求(DER)与食材搭配；
   * 📑 **宠物健康档案管理**：支持多爱宠档案录入与体征追踪；
   * 🛍️ **鲜食选购与在线商城**：支持商品挑选与一键加购出库；
   * 📊 **批次库存与效期预警大屏**：ECharts 图表、先进先出 (FIFO) 扣减与短保效期(≤3天)预警。

---

## 二、 运行指南

### 1. 导入数据库
运行 `sql/init_schema.sql` 脚本重置最新数据库结构。

### 2. 启动 Spring Boot 后端
在 `backend/` 下运行：
```bash
mvn clean spring-boot:run
```
端口为 `http://localhost:8080`。

### 3. 启动 Vue 3 前端
在 `frontend/` 下运行：
```bash
npm install
npm run dev
```
浏览器访问 `http://localhost:5173` 即可畅通操作多模块切换与登录注册。
